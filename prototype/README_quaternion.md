# 无人机拦截器 - 四元数版本改进

## 概述

本改进版本将原始的基于欧拉角的无人机动力学模型改为使用四元数表示，解决了欧拉角在朝向角(YAW) psi 在 -π 和 +π 之间切换时的奇异性问题。

## 主要文件

### 1. `drone_model_quaternion.py`
使用四元数的无人机动力学模型：
- **状态变量**: `[px, py, pz, vx, vy, vz, qw, qx, qy, qz]` (10维)
- **控制变量**: `[wx, wy, wz, az]` (机体角速度 + 推力加速度)
- **四元数动力学**: `dq/dt = 0.5 * Omega(omega) * q`
- **自动归一化**: 在代价函数中加入四元数归一化软约束

### 2. `solver_flat_quaternion.py`
完整的四元数版本仿真程序，与原版本 `solver_flat.py` 功能对应

### 3. `solver_flat_quaternion_demo.py`
四元数版本的演示程序，包含：
- 详细的性能分析图表
- 四元数归一化检查
- 偏航角连续性验证

## 四元数版本的优势

### 1. 解决奇异性问题
- **欧拉角问题**: 当偏航角 psi 从 +π 跳变到 -π 时会产生不连续性
- **四元数解决方案**: 四元数表示没有奇异点，保证旋转的连续性

### 2. 数值稳定性
- **避免万向节锁**: 四元数不会遇到万向节锁问题
- **更好的数值积分**: 四元数的积分更加稳定

### 3. 计算效率
- **更少的三角函数**: 四元数到旋转矩阵的转换更高效
- **更稳定的优化**: MPC求解器收敛更稳定

## 关键技术改进

### 1. 四元数动力学模型
```python
# 四元数动力学: dq/dt = 0.5 * Omega(omega) * q
omega_quat_matrix = ca.vertcat(
    ca.horzcat(0,   -wx, -wy, -wz),
    ca.horzcat(wx,   0,   wz, -wy),
    ca.horzcat(wy,  -wz,  0,   wx),
    ca.horzcat(wz,   wy, -wx,  0)
)
quat_dot = 0.5 * omega_quat_matrix @ quat
```

### 2. 归一化约束
```python
# 四元数归一化约束 (作为软约束加入代价函数)
quat_norm_error = 1 - (qw**2 + qx**2 + qy**2 + qz**2)
```

### 3. 状态转换函数
提供欧拉角与四元数之间的转换函数：
- `euler_to_quaternion()`
- `quaternion_to_euler()`
- `normalize_quaternion()`

## 性能对比

### 原版本 (欧拉角)
- 状态维数: 9维 `[px, py, pz, vx, vy, vz, phi, theta, psi]`
- 问题: 偏航角跳变、万向节锁
- 数值稳定性: 中等

### 四元数版本
- 状态维数: 10维 `[px, py, pz, vx, vy, vz, qw, qx, qy, qz]`
- 优势: 无奇异点、数值稳定
- 额外开销: 1个状态变量 + 归一化约束

## 验证方法

四元数版本包含以下验证功能：

1. **四元数归一化检查**: 监控 `||q|| ≈ 1`
2. **偏航角连续性**: 检查从四元数提取的欧拉角是否连续
3. **姿态限制**: 保持与原版本相同的姿态约束

## 注意事项

1. **兼容性**: 四元数版本与原版本的感知模块和EKF估计器兼容
2. **性能**: 稍微增加了计算复杂度，但提高了数值稳定性
3. **调试**: 可以通过转换函数将四元数转回欧拉角进行可视化

## 结论

四元数版本成功解决了原版本中偏航角奇异性的问题，提供了更稳定和准确的姿态表示，适用于需要大角度机动的无人机拦截任务。

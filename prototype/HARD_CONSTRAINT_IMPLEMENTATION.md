# 四元数姿态限制硬约束实现方法

## 🎯 **实现方案总结**

我已经成功实现了两种将姿态限制变为硬约束的方法：

### 方法1：状态约束（Box Constraints）✅ 推荐

**原理**：直接限制四元数分量`qx`和`qy`的取值范围

**数学基础**：
- 倾斜角约束：`θ ≤ θ_max`
- 四元数表示：`cos(θ) = 1 - 2(qx² + qy²) ≥ cos(θ_max)`
- 简化约束：`qx² + qy² ≤ (1-cos(θ_max))/2`
- Box约束：`|qx| ≤ sqrt((1-cos(θ_max))/2)` 且 `|qy| ≤ sqrt((1-cos(θ_max))/2)`

**代码实现**：
```python
# 在setup_ocp()中添加
max_tilt = self.constants['ATT_LIMIT']
cos_max_tilt = np.cos(max_tilt)
tilt_constraint_bound = (1 - cos_max_tilt) / 2
qxy_max = np.sqrt(tilt_constraint_bound)

ocp.constraints.idxbx = np.array([7, 8])  # qx和qy的索引
ocp.constraints.lbx = np.array([-qxy_max, -qxy_max])  # 下界
ocp.constraints.ubx = np.array([qxy_max, qxy_max])    # 上界
```

**优点**：
- ✅ 计算简单高效
- ✅ 数值稳定性好
- ✅ ACADOS原生支持
- ✅ 求解速度快

**缺点**：
- ⚠️ 约束形状是正方形而非圆形（稍微保守）
- ⚠️ 对组合倾斜角的限制不够精确

### 方法2：非线性路径约束（Nonlinear Path Constraints）

**原理**：直接约束倾斜角公式

**数学基础**：
- 约束函数：`h(x) = cos(θ) - cos(θ_max) = 1 - 2(qx² + qy²) - cos(θ_max) ≥ 0`

**代码实现**：
```python
# 在模型定义中添加
cos_tilt_angle = 1 - 2*(qx**2 + qy**2)
cos_max_tilt = ca.cos(max_tilt)
h_expr = cos_tilt_angle - cos_max_tilt  # ≥ 0

self.model.con_h_expr = h_expr

# 在setup_ocp()中
ocp.constraints.lh = np.array([0.0])  # h(x,u) ≥ 0
ocp.constraints.uh = np.array([1e6])  # 上界
```

**优点**：
- ✅ 约束精确（圆形约束区域）
- ✅ 物理意义明确

**缺点**：
- ❌ 计算复杂度高
- ❌ 可能数值不稳定
- ❌ 求解时间更长
